## Layout

- `registers/people.csv` — one row per person (unique ID, names, events, confidence).
- `registers/relationships.csv` — one row per parent-child or spouse link, with evidence.
- `registers/sources.csv` — one row per document or web record.
- `registers/discrepancies.csv` — conflicting facts and how each was resolved.
- `research_log.md` — every question asked, search run, and result.
- `charts/` — family tree and map files (to be generated once data exists).
- `sources/` — copies of supplied documents.

All registers are empty templates until the spreadsheet is read.
